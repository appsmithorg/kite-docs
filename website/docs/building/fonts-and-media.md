# Fonts & Media

Your fonts and media are a big part of your brand. Kite lets you choose fonts and add media so your site looks and feels like yours.

## Choosing fonts

Kite sites use Google Fonts, so you can ask for any font in the Google Fonts library by name. You do not upload font files.

1. Decide where the font should apply: the whole site, just headings, or one section.
2. Tell Kite the font name. For example:

> Use "Poppins" for all headings and "Inter" for body text across the whole site.

3. Preview and check that text is still readable at all sizes.

:::tip
Be specific about where the font goes. "Use this font for headings" gives a cleaner result than "change the font," which can leave some text behind.
:::

:::note Custom font files
Kite does not accept uploaded font files (`.otf`, `.woff2`, and so on). If your brand font is not on Google Fonts, ask Kite to suggest the closest Google Font.
:::

## Adding video

You can upload video in **MP4, WebM, MOV, or OGG**, up to **100 MB** per file.

> Add a background video to the hero section on the **Home** page using the file I'm uploading.

For longer or larger videos, upload to a video platform and ask Kite to embed it.

## Adding images

Images can be **PNG, JPG, WebP, GIF, HEIC, SVG, TIFF, BMP, ICO, or AVIF**, up to **10 MB** per file. See [Images & Logos](/building/images-and-logos).

## General media tips

- **Keep files reasonably sized.** Very large media files slow down your page for visitors.
- **Use good source quality.** Kite cannot improve a low-quality original.
- **Check mobile.** Media that looks great on desktop can crop or overflow on phones. See [Mobile & Responsive Design](/building/responsive-design).
- **Make one change at a time.** Apply a font, preview it, then move on.

## Troubleshooting

- **Font did not apply everywhere:** Tell Kite specifically which text should use it (headings, body, buttons), one area at a time.
- **Font not found:** Check the spelling against [fonts.google.com](https://fonts.google.com).
- **Video will not upload:** Check the format and the 100 MB limit, or embed a hosted video instead.
- **A media change is not showing live:** Publish again and refresh. See [Changes Not Showing](/publishing/changes-not-showing).
