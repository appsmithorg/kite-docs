# Working with Kite in Slack

Kite is your AI marketer in Slack. Slack is where you ask Kite for work, where it brings you offers, drafts, digests, and results, and where a quick reply keeps things moving. This section explains the day-to-day experience.

## The basic rhythm

1. You ask for something in a thread, or Kite offers it.
2. Kite does the work: research, drafting, building, sending.
3. Kite posts the result in the same thread.
4. You reply with changes, or with the word to ship it, or with nothing at all if Kite already shipped routine work.
