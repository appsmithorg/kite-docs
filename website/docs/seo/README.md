# SEO & Discoverability

SEO (search engine optimization) is everything that helps people find your site when they search. This section explains what Kite takes care of for you, what you can ask Kite to fine-tune, and how to move an existing site over.

## What Kite handles automatically

When you build and publish a site with Kite, the technical groundwork is done for you:

- **Page titles and headings** are generated from your content as Kite builds each page.
- **A live `sitemap.xml`** lists your pages and updates itself as they change. See [Sitemap & robots.txt](/seo/sitemap-and-robots).
- **A `robots.txt`** that welcomes search engines and AI crawlers.
- **An `llms.txt` file and structured data**, so AI answer engines can read and cite your site.
- **Google Search Console verification and sitemap submission** after publish, on paid plans, with the status shown in the publish panel.
- **Mobile-friendly, responsive layouts.** See [Responsive design](/building/responsive-design).

## The Discoverability tab

Your site's Analytics page has a **Discoverability** tab with page speed scores, an AI analysis of how well your site can be found, and a **Review and fix** button that hands the findings to Kite. See [Site analytics](/forms-integrations/analytics).

## What you can ask Kite for

You do not edit code in Kite. You describe what you want in plain language and Kite makes the change. For SEO, you can ask Kite to:

- Set or rewrite a page's **title** and **meta description**. See [SEO Basics](/seo/seo-basics).
- Add **alt text** to images. See [SEO Basics](/seo/seo-basics).
- Set the **social preview** (title, description, image) for a page. See [Social Link Previews](/seo/social-previews).
- Audit the site for discoverability problems and fix them. See [Conversion work](/capabilities/conversion-fixes).

:::tip
The clearer your request, the better the result. Instead of "improve my SEO," try "Set the meta description on our Home page to: Scheduling software for multi-location clinics. Book a demo in two minutes."
:::

## Set expectations on timing

Search engines do not see your changes instantly. After you publish, Google has to **crawl** (visit) and **index** your site before updates show up in search results. This can take days or weeks. See [SEO Basics](/seo/seo-basics).
