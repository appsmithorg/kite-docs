# Ways to Work with Kite

You can reach Kite in four places. They all talk to the same Kite, with the same knowledge of your business, the same work in progress, and the same credits.

| Where | Best for |
|---|---|
| **Slack** | Day-to-day requests, reviewing drafts, approvals, and Kite's updates and digests |
| **Browser workspace** | Hands-on website editing, publishing, analytics, experiments, integrations, and billing |
| **Email** | Forwarding things to Kite, and working with Kite when you're away from Slack |
| **ChatGPT** | Checking on Kite's work, your site's numbers, and quick website changes without leaving ChatGPT |

## Slack

Slack is Kite's home. Ask for work in a thread or a direct message, and Kite researches, drafts, builds, and posts the result in the same thread. Kite also brings you ideas on its own. See [Working with Kite in Slack](/slack/).

## Browser workspace

Sign in at kite.ai to open the browser workspace. Chat with Kite there just as you would in Slack, or work on your website directly: click to edit, preview, and publish. The browser workspace is also where you read [analytics](/forms-integrations/analytics), run [A/B experiments](/capabilities/ab-experiments), connect [integrations](/forms-integrations/integrations), and manage your [plan](/pricing-credits/).

## Email

Your team has its own Kite email address, such as `yourteam@kite.space`. To find it, open your team's **Settings** and look under **Kite's email address**. Everyone on the team can see it. Admins and owners can rename it, and email to an old name still reaches Kite.

Kite also sends your team's outgoing email, such as campaigns and sequences, from this address.

Email Kite to:

- Forward something for Kite to act on, such as a customer question, a partner's request, or a newsletter worth responding to.
- Ask for work when you're away from Slack.

Kite reads each email and decides what it needs. It might reply, forward it, start the work, or post a note to your team. It doesn't send an automatic reply to every message. Email uses credits like any other request. If your team is out of credits, Kite tells you by email instead of doing the work.

## ChatGPT

Connect the **Kite** app in ChatGPT to check on Kite's work, read your site's analytics, and request, merge, and publish website changes. ChatGPT asks you to confirm before it changes anything. See [Kite for ChatGPT](/get-started/kite-for-chatgpt).

## What you can do where

| Task | Slack | Browser | Email | ChatGPT |
|---|---|---|---|---|
| Ask for research or content | ✓ | ✓ | ✓ | |
| Ask for a website change | ✓ | ✓ | ✓ | ✓ |
| Check on Kite's work | ✓ | ✓ | | ✓ |
| Approve or revise Kite's drafts | ✓ | ✓ | | Merge only |
| Publish your website | ✓ | ✓ | | ✓ |
| Undo a change or restore a version | ✓ | ✓ | | See versions only |
| Read analytics | Ask Kite | ✓ | Ask Kite | ✓ |
| Start or end an A/B experiment | | ✓ | | |
| Manage billing, team, and integrations | | ✓ | | |

Starting and ending A/B experiments is browser-only on purpose. It changes what real visitors see, so a signed-in team member does it. See [A/B experiments](/capabilities/ab-experiments).
